# 首页顶部精简设计

## 目标

优化管理端首页顶部的信息层级，去掉“重新加载”和“业务数据”两个按钮，让用户进入首页后更快聚焦欢迎信息、系统健康状态及下方仪表盘数据。

## 选定方案

采用方案 A（保守精简）：保持当前欢迎标题、健康状态和日期时区的横向信息结构，移除标题右侧的操作区。现有字体、颜色、间距及响应式行为保持不变。

## 实现范围

- 从 `apps/frontend/src/views/home/index.vue` 的首页顶部移除两个按钮。
- 删除仅为这两个按钮服务的 `refreshing` 状态、`refreshHome` 方法和 `scrollToDashboard` 方法。
- 保留权限加载失败页面上的重试按钮；该按钮属于错误恢复流程，不在本次移除范围内。
- 不修改下方仪表盘模块、数据请求、权限判断、实时连接或国际化文案。

## 交互与状态

首页正常状态的顶部不再提供手动刷新或滚动入口。首次进入页面仍由 `onMounted(initializeHome)` 自动加载数据；数据模块自身已有的重试入口继续保留。

## 响应式与可访问性

移除操作区后，顶部只包含左侧信息块，在桌面和移动端均自然左对齐。现有语义化 `header`、`h1` 和健康状态文本保持不变，不引入新的交互元素或键盘操作。

## 验证

- 静态检查首页源码中不再包含两个顶部按钮及对应的废弃逻辑。
- 运行前端类型检查。
- 在可用的本地首页环境中验证桌面与窄屏顶部布局，确认无多余留白、截断或错位。
